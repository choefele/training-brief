Training Brief

Settings. Export your Garmin Connect™ activities for an AI chat. Everything stays in this browser.

Connect to Garmin

Connected

  1. In Garmin Connect™, create a Personal API key. Garmin's Personal API page explains where; the key page is in your Garmin Connect account.
  2. Paste the key here. Training Brief trades it for an access token that lasts up to 24 hours, then loads your activities.

This looks like an access token. It works until it expires (at most 24 hours); after that you'll need to paste a new one, or your key.

Your key is personal. Garmin's terms allow it only in tools you use for yourself and forbid sharing it. Training Brief stores it only in this browser and sends it only to Garmin, never into an export.

About
